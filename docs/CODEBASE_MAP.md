# Meetily Codebase Map

> Auto-generated by Cartographer. Last mapped: 2026-08-14  
> Project tier: Large (716 files, ~1.63M tokens)

Meetily is a **privacy-first AI meeting assistant** desktop application built with Tauri v2 (Rust + Next.js). It captures, transcribes, and summarizes meetings entirely on local infrastructure — no cloud dependency required.

### Core Capabilities
- **Audio Capture**: Professional-grade microphone + system audio mixing with VAD filtering
- **Transcription**: Whisper.cpp (local) / Parakeet ONNX streaming / Ollama paths
- **Summarization**: Multi-provider AI (Ollama, Claude, Groq, OpenAI, OpenRouter) with chunked processing and caching
- **Storage**: SQLite via sqlx for meetings/transcripts/summaries; local filesystem for audio files

## Architecture Summary

Meetily is a **desktop application** built with:
- **Tauri 2.x** — Cross-platform desktop wrapper (Rust backend + web frontend)
- **Next.js 14+** — React UI framework (App Router)
- **Rust** — Native audio capture (cpal), Whisper.cpp inference (whisper-rs), Parakeet ONNX (ort), SQLite storage (sqlx), local built-in AI (llama-helper sidecar)

### Key Capabilities

| Capability | Technology | Module |
|------------|------------|--------|
| Audio recording (mic + system) | cpal + per-channel VAD + stereo mixing pipeline | `audio/` |
| Speaker diarization | polyvoice ONNX (segmentation + ResNet34 embeddings + clustering), offline + online | `audio/diarization.rs`, `audio/online_diarization.rs` |
| Meeting audio playback | FFmpeg WAV transcode + `convertFileSrc` streaming | `audio/audio_file.rs`, frontend `AudioPlayer` |
| Live transcription | Whisper.cpp / Parakeet ONNX | `whisper_engine/`, `parakeet_engine/`, `audio/transcription/` |
| AI summarization | Multi-provider LLM (Ollama/Claude/Groq/OpenAI/OpenRouter + built-in AI) | `summary/` + providers |
| Meeting storage | SQLite (sqlx) + local filesystem | `database/` |
| Desktop notifications | Tauri notification API | `notifications/` |
| Analytics | PostHog anonymous telemetry | `analytics/` |
| Device management | Platform-specific detection (WASAPI/CoreAudio/ALSA) | `audio/devices/platform/`, `device_detection.rs` |
