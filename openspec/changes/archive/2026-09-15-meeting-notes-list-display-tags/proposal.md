## Why

Список записей в Meeting Notes показывает только заголовок встречи крупным шрифтом: не видно когда была запись, длинные названия обрезаются, нет способа помечать и различать встречи. Пользователь хочет компактный список с датой/временем и цветными тэгами.

## What Changes

- Каждая строка списка Meeting Notes показывает дату и время записи в формате `yyyy-mm-dd hh:mm` (24h, локальный часовой пояс).
- Типографика списка уплотняется (уменьшенный шрифт заголовка и мета-строки) чтобы помещалось больше текста и больше записей без прокрутки.
- Вводится система тэгов встреч: создание нового тэга, выбор из существующих, снятие тэга со встречи, удаление/переименование тэга.
- Каждый тэг имеет цвет: по умолчанию назначается циклически/детерминированно из фиксированной палитры, с возможностью ручного переопределения.
- Строка списка отображает тэги встречи (компактные пилюли, максимум N + счетчик `+M` при переполнении).
- Отображение остается списком (не таблицей): сайдбар `w-64` физически не вмещает таблицу; решение — обогащенные двухэтажные строки списка.

## Capabilities

### New Capabilities

- `meeting-tags`: словарь тэгов (имя уникально без учета регистра, цвет), связь многие-ко-многим встреча-тэг, CRUD и назначение/снятие, каскадное удаление связей при удалении встречи.
- `meeting-list-display`: правила отображения строки списка — формат даты/времени, уплотненная типографика, отображение тэгов с цветами, состояния переполнения, сортировка по `created_at DESC`.

### Modified Capabilities

- `database`: новая миграция (`meeting_tags`, `meeting_tag_links`), индексы, каскадное удаление связей в `delete_meeting_with_transaction`; чтение списка встреч возвращает `created_at` + тэги.

## Impact

- Rust: новая миграция SQLx, `MeetingModel`/DTO (`created_at`, `tags`), новые Tauri-команды (`list_tags`, `create_tag`, `rename_tag`, `delete_tag`, `assign_tag`, `unassign_tag`, расширенный `api_get_meetings`), регистрация команд в `lib.rs`, обновление `delete_meeting_with_transaction`.
- Frontend: `SidebarProvider` пробрасывает `created_at`+`tags` (сегодня отбрасывает все кроме `id/title`), `Sidebar/index.tsx renderItem` — новый layout строки, форматирование даты `yyyy-mm-dd hh:mm`, компонент пилюль тэгов, поповер/диалог выбора и создания тэгов, палитра цветов.
- Поиск/фильтр: существующий фильтр по title/транскрипту расширяется учетом тэгов (без ломки текущего поведения).
- Миграция обратима; существующих встреч не касается (тэгов у них изначально нет).
