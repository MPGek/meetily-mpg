- Posterior stitching: no escape hatch needed — per-chunk binarized segmentation
  with 5 s chunk overlap feeds the global clustering + Hungarian + resegmentation
  stages directly (design D1).
- AHC on the new core reproduces old-core confusion within ~1.6 pp (20.14 vs
  18.53); the delta is attributable to dense 5 s windows + hysteresis
  binarization changing segmentation/embeddings.
- NME-SC does **not** improve on the tuned AHC baseline (37.27 vs 18.53 with
  the coverage fix; 35.47 before it): the normalized eigengap picks k≈1 on
  dense TitaNet windows (mean 1.33 speakers/file, 158/216 single-label outputs
  vs 28/216 for the AHC probe). Usage matches the vendored trait contract
  (L2-normalized inputs, `NmeScClusterer::new(ceiling)`); this is clusterer
  quality, not API misuse. Consequence: task 6.2 must decide the shipped
  default (nmesc vs ahc re-tune).
- Coverage fix (single-cluster channels now emit overlap spans with their
  primary instead of leaving holes): dev nmesc Miss 8.74 → 4.55, DER 46.21 →
  43.86; ru-youtube nmesc Miss 12.09 → 4.36, DER 61.47 → 58.85 (recovered
  coverage converts Miss into Conf on under-clustered channels: dev Conf
  35.47 → 37.27, ru Conf 32.32 → 36.14). 29/29 diarization unit tests pass.

### Wall-time factor (12-file subset, same machine)

Old core (sparse AHC, `baseline-oldcore-timing.txt`): 54.46 s total.
v2 + NME-SC defaults (fixed binary): 120.16 s total → factor **2.21×**,
within the ≤3× budget. (Pre-fix composition measured 1.46×; the turn-assembly
fix below added no embedding/segmentation work — delta is machine variance.)

### Composition bug found and fixed (3.5 correction)

First v2 run emitted one primary turn per dense window: with `gap_merge_secs=0`
long segments tiled into overlapping 5 s window-turns (AHC: FA **63.02**),
and alternating window labels double-covered time. Fix: one primary turn per
source segment (duration-weighted majority label), region-primary turns split
at mapped overlap spans (resegmenter re-emits the pair there), fallback spans
unsplit. Post-fix AHC: FA 63.02 → 4.18. Unit tests added:
`dense_windows_emit_single_segment_turn_without_gap_fill`,
`mapped_overlap_splits_region_primary_without_losing_coverage`
(28/28 diarization tests pass). Design D1 amended.

## 1.3 — Degenerate-count probes + vendored constants

- hqyok.wav (22 s, reference: single speaker spk00): 1 label, single [0,22] turn.
  No fragmentation on a <30 s single-speaker clip.
- ru-synthetic `train-00000-of-00030_0000.wav`: 2 alternating labels plus one
  genuine overlap pair (two same-span turns, distinct speakers). No explosion.
- Vendored `BinarizationConfig::default` (polyvoice 0.17.0 `binarize.rs`):
  onset=0.5, offset=0.5, min_on=0.0, min_off=0.0 — plain thresholding.
  Shipped constants (hysteresis): 0.5/0.4/0.2/0.2.
- VBx/PLDA: vendored PLDA transforms into the 128-d VBx space from 256-d
  embeddings (default manifest profile `embedding_dim = 256`, ResNet34 family);
  feeding the enhanced 192-d TitaNet family would fail shape checks — hence the
  `vbx` gate (actionable error, no silent switch). No PLDA asset bundled
  (~265 KB, CC-BY-4.0 pyannote-derived, 256-d-locked).
- NME-SC quality on ru-youtube (6 files / 4.97 h, fixed binary):
  nmesc DER 58.85 (FA 18.36 / Miss 4.36 / Conf 36.14) vs AHC thr0.52/ceil64/gap0.0
  DER 65.12 (FA 27.89 / Miss 4.50 / Conf 32.72) vs old-core report DER 65.63
  (FA 25.62 / Miss 4.23 / Conf 35.77). nmesc Conf now trails AHC by ~3.4 pp
  (was tied pre-fix); both beat the old 35.77 on Conf.

## 6.2 — Default-kind decision (nmesc vs ahc)

Evidence matrix (Conf; lower is better):

| Dataset | nmesc (new core) | AHC (new core) | Old-core AHC report |
| --- | ---: | ---: | ---: |
| voxconverse-dev (tuning) | 37.27 | 14.80 (thr0.60/ceil128/gap0.3) | 18.53 (thr0.52/ceil64) |
| voxconverse test (held-out) | 41.88 | pending (`v2-ahc`) | 21.45 |
| msdwild (held-out) | 26.78 (gate < 28.27: PASS) | pending (`v2-ahc`) | 28.84 |
| ru-youtube | 36.14 | 32.72 | 35.77 |
| ru-synthetic (Conf-only) | 9.09 | — | 8.59 |

NME-SC fails the no-regression gate on voxconverse-dev (-test) decisively
while passing msdwild; AHC re-tune sweep (`sweep-2026-09-07-v2retune.md`)
selects thr 0.60 / ceil 128 / gap 0.3 — the already-shipped numeric defaults.
Decision: built-in default kind switches `nmesc` → `ahc`, numeric values
unchanged; `nmesc` stays selectable. Held-out `v2-ahc` validation decides
re-baseline (6.3).
