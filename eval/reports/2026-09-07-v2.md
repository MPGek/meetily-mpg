## 6.2 kind decision (nmesc vs ahc)

NME-SC as the default failed the gates on real-data sets (dev Conf 37.27,
voxconverse-test Conf 41.88 vs 21.45) while passing msdwild (26.78); root
cause is eigengap under-clustering of dense TitaNet windows (mean 1.33
speakers/file), not API misuse. The AHC re-tune sweep on the dev pool
selected thr 0.60 / ceil 128 / gap 0.3 (Conf 14.80) — the already-shipped
numbers — so the built-in default kind switches to `ahc` with unchanged
numeric values. `nmesc` stays selectable; `vbx` stays gated. Held-out
validation above confirms the selection across all four sets.
